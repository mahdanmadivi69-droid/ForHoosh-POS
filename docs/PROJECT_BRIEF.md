# سند مشخصات اولیه پروژه (PROJECT BRIEF) — SmartOrders

## ۱. معرفی و بیانیه مأموریت
پروژه **SmartOrders** یک سامانه SaaS متمرکز بر خدمات صندوق فروشگاهی (POS)، مدیریت نوبت‌های کاری (Shift Management)، ثبت پرداخت‌ها و تحلیل شفاف مالی کافه‌ها و اماکن کوچک پذیرایی است. 
هدف غایی، ساخت کوچک‌ترین محصول ارزشمند و قابل فروش (MVP) با بالاترین ضریب اطمینان عملیاتی، دقت در محاسبات ریالی/تومانی و سهولت بی‌نظیر برای باریستا و صندوق‌دار است.

## ۲. بازیگران و نقش‌ها (User Roles)
1. **مالک / مدیر ارشد (Owner / Admin):** مشاهده تمام گزارشات سود، هزینه‌ها، تنظیمات کافه، مدیریت قیمت‌های منو و کاربران.
2. **مدیر شیفت (Shift Manager):** باز کردن و بستن شیفت، ثبت هزینه‌ها، نظارت بر مغایرت‌های نقدی صندوق، ابطال یا اعمال تخفیف.
3. **صندوق‌دار / باریستا (Cashier / Barista):** ثبت سریع سفارشات سالن/بیرون‌بر، دریافت وجه نقد یا کارت، صدور فیش و چاپ.

## ۳. قابلیت‌های کلیدی نسخه MVP
| ماژول | قابلیت‌های اصلی |
| :--- | :--- |
| **چندمستأجری و احراز هویت** | تفکیک قطعی دیتای کافه‌ها، شناسه مستأجر (Tenant ID) در تمام رکوردها، کنترل سطح دسترسی بر اساس نقش. |
| **مدیریت منو و قیمت‌ها** | دسته‌بندی اقلام (نوشیدنی گرم، سرد، کیک و دسر و...)، قیمت‌گذاری بر پایه تومان، تغییر وضعیت فعال/غیرفعال، تثبیت تاریخی قیمت در فاکتورهای ثبت‌شده قبلی. |
| **صندوق فروش (POS)** | ثبت سفارش سریع، انتخاب میز یا نام مشتری، اعمال درصد یا مبلغ تخفیف، سبد خرید زنده با خلاصه حساب فوری. |
| **ثبت پرداخت‌ها** | تفکیک دقیق بین پرداخت نقدی (با محاسبه خودکار باقیمانده پرداختی به مشتری) و کارتخوان (ثبت شماره پیگیری و پایانه)، جلوگیری از ثبت تکراری. |
| **مدیریت شیفت (Shifts)** | ثبت موجودی اولیه نقد در کشو، ردیابی فروش نقد در طول شیفت، بستن شیفت با شمارش فیزیکی اسکناس، محاسبه خودکار کسر یا مازاد صندوق و ثبت دلیل. |
| **مدیریت هزینه‌ها** | ثبت خریدهای روزمره کافه (شیر، شکر، یخ، تعمیرات فوری) متصل به شیفت جاری، کسر از صندوق نقد یا پرداخت خارج از صندوق. |
| **گزارشات روزانه و شیفت** | گزارش جامع با فرمول‌های دقیق: ناخالص فروش، تخفیف، خالص فروش، نقد ورودی، واریز کارتخوان، هزینه‌ها، و مغایرت صندوق. |
| **حسابرسی (Audit Trail)** | لاگ دائمی و غیرقابل تغییر برای رویدادهای مالی حساس. |

## ۴. قواعد و اصول محاسبات مالی
- **قانون شماره ۱:** تمامی مبالغ در دیتابیس به صورت عدد صحیح (Integer) بر واحد **تومان** ذخیره می‌شوند. هیچ‌گونه عدد اعشاری ممیز شناور (Float) برای وجه پول استفاده نمی‌شود.
- **قانون شماره ۲:** 
  $$\text{خالص فروش (Net Revenue)} = \text{ناخالص فروش (Gross Sales)} - \text{تخفیف (Discounts)}$$
- **قانون شماره ۳:** 
  $$\text{نقد مورد انتظار در صندوق} = \text{موجودی اولیه} + \text{مجموع دریافتی نقدی} - \text{هزینه‌های پرداخت‌شده از صندوق}$$
- **قانون شماره ۴:** 
  $$\text{مغایرت نقدی (Discrepancy)} = \text{نقد شمرده‌شده واقعی} - \text{نقد مورد انتظار}$$
- **قانون شماره ۵:** تغییر قیمت یک آیتم در منو هرگز نباید قیمت آیتم‌های سفارشات ثبت‌شده قبلی را تغییر دهد (Historical Immutability).
